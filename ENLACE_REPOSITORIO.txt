DESCRIPCIÓN DEL PROYECTO CODIFICADO:
================================================================================
Proyecto: App de Control Avícola - Pollos ElDorado
Módulo: Registro y persistencia de mortalidad de aves por galpón.

TECNOLOGÍAS UTILIZADAS:
- Lenguaje: Java (JDK 21)
- Servlets y JSP: Jakarta EE 10 (Servlet API 6.0)
- Gestor de dependencias y construcción: Apache Maven
- Servidor Web / Contenedor de Servlets: Apache Tomcat 10.1.61
- Base de Datos: MySQL Server 8.0 (vía JDBC con MySQL Connector/J)
- Interfaz de Usuario: HTML5 y CSS3 responsivo

INSTRUCCIONES RÁPIDAS DE DESPLIEGUE:
1. Ejecutar el script SQL incluido en el proyecto: `schema.sql` en MySQL.
2. Compilar con Maven: `mvn clean package`.
3. Desplegar el archivo `pollos-eldorado.war` generado en la carpeta `webapps/` de Tomcat.
4. Acceder en el navegador a: http://localhost:8080/pollos-eldorado/
